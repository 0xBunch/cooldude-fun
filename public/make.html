MAKE A GAME

Anyone can add a game to the arcade — even with no coding. Here's how.

1. Ask an AI to build it

Open Claude (or any chat that makes web pages) and paste this recipe. Change the idea to whatever game you want!

Make me a single-file HTML game for Cool Dudez Arcade.

Rules:
1. Put EVERYTHING in ONE .html file — all the HTML, CSS, and JavaScript inline. No separate files, no internet links, no build step.
2. It must work when I just open the file in a browser.
3. When the game ends and there's a final score, call exactly this line:
       window.Arcade?.submitScore(finalScore);
   (finalScore must be a whole number. The "?." keeps it safe outside the arcade.)
4. Optional: you can greet the player using their name from  window.Arcade?.nickname
5. Make it colorful, fun, and kid-friendly for a 9-year-old.

My game idea: A spaceship that dodges asteroids and scores points for surviving.

Give me the full .html file so I can save it.

2. Save the file

Save what the AI gives you as a file ending in .html. The file's name becomes the game's name — so Asteroid Dash.html shows up as “Asteroid Dash”.

3. Drop it in the Drive folder

Put the .html file into the arcade's shared Google Drive folder. That's it — it shows up in the arcade within about a minute. Want a custom picture on the tile? Drop an image with the same name next to it (e.g. Asteroid Dash.png).

That's it!

Your friends can play it and chase the top score. Back to the arcade ▸
